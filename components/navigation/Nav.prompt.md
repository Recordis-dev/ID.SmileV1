The global bar. One per page, sticky, translucent over whatever scrolls beneath.

```jsx
<Nav brand="Aperture" items={["Halo", "Studio", "Support"]} active="Halo" actions={<Icon name="search" size={16} />} />
```

48px tall, 13px links at 72% opacity rising to 100% on hover, 1px hairline underneath. Use `tone="dark"` when the page opens on a dark stage.
