The system's only button; always a full pill, never a rounded rectangle.

```jsx
<Button variant="primary" size="lg">Buy</Button>
<Button variant="ghost" iconRight="chevron-right">Learn more</Button>
```

Variants: `primary` (accent fill — exactly one per view), `secondary`, `outline`, `inverse` (on dark stages), `ghost` (inline link, no box). Press state scales to 0.97; hover only shifts the fill one step. Labels are one or two words, sentence case, no trailing punctuation.
