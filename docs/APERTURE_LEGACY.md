# Aperture UI Kit & Guidelines (Legacy / Historial)

En la iteración de agosto de 2026, el repositorio fue reestructurado para utilizar un enfoque de HTML semántico, CSS nativo y Vanilla JS para el proyecto de **ID Smile** (en lugar de componentes de React).

Los 78 archivos base de `aperture_web`, sus directrices de diseño (`guidelines/`), tokens (`tokens/`) y componentes prefabricados (`components/`) fueron retirados del árbol de trabajo principal para aligerar la carga de despliegue en GitHub Pages y prevenir conflictos con el motor de integración.

## ¿Dónde encuentro estos archivos?
Estos archivos **no se han perdido**. Si requieres auditar o consultar el código original en React de la marca Aperture, puedes encontrar la versión completa de los mismos explorando el **Commit Inicial** (hash: `883c706d3dade5d81162c27e5c3736f056bb294a`) en el historial de Git.
